# 油站班次路线稽核台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在巡检清单基础上扩展的班次路线稽核闭环：

- 每班选择区域和巡检人，按点位顺序生成路线；同一班次同一区域只能有一条有效路线。
- 到场确认不能越序，越序尝试会被记录。
- 漏检点位可申请跳过，须选原因并指定补检班次；未经核准不能结班。
- 结班时列出漏检、越序和取消点位；已结班路线冻结，更正保留原记录并另写原因。
- 数据经 Zustand persist 存入 localStorage，刷新后班次、路线、补检和更正链保持一致。

## 目录结构（数据 / 规则 / 界面分离）

- `src/data/points.ts`：点位数据（区域、点位顺序、班次、巡检人、跳过原因）
- `src/domain/audit.ts`：稽核规则纯函数（路线生成、越序校验、跳过核准、结班小结、更正链）
- `src/store.ts`：Zustand 状态与持久化，所有变更经由规则函数
- `src/components/`：界面（开班、路线稽核卡、补检任务）
